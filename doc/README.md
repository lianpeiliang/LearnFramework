## 三条贯穿全文的线索

**启动线：** `main → ApplicationHost → 命令 1000 → PluginLoader → RuntimeUiLoader → WidgetContainer`。

**交互线：** `FWidget → 命令 2000 → DevicePlugin → 状态消息 3000 → F/G 面板`。

**清理线：** `主窗口 → 内容窗口 → 工厂回调 → 插件资源与通信回调 → 插件加载引用`。

可以边读边在纸上画出这三条线；能不看文档复述它们，就已经抓住框架的主干。

## 如何理解文中的代码

标为“源码片段”的代码来自项目；标为“教学简化”或“练习”的代码帮助理解，不表示仓库里已经实现。源码链接指向本机当前项目；章节之间使用相对链接，便于在 Markdown 阅读器中跳转。

这里介绍的是实际实现，并非把所有理想功能都算作已有功能。例如刷新间隔没有驱动采集定时器，报表没有保存到磁盘，加载器也没有实现 DLL 热更新。

本次做的是源码分析与文档检查，没有重新编译程序或执行 Qt 测试。第 9 章会区分“现有测试检查什么”和“本次实际验证了什么”。
